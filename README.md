# ML_EX_1

## Project Overview

For training a model, use the main.py file, adjust hyperparameters and settings in utils.py and visualize the dataset with visualization_data.py.

## Installing dependencies

Before running the project is necessary to install all dependencies. Do it by running 
```pip install -r requirements.txt```




## Files and Usage

1. main.py
This is the main script for executing the training process.

2. utils.py

In this file, you'll find configurations and hyperparameters that you can tweak to optimize the model's performance.
Adjust hyperparameters and settings according to your specific use case.
Additionally, this file is equipped with options for performing a grid search to find the best combination of hyperparameters.

3. visualization_data.py

This file contains functions to visualize the dataset. It is possible to choose between GPU plots (faster) or CPU
